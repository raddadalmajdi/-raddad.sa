# روابط الدفع (أدمن → واتساب)

## للأدمن

1. افتح `/admin.html` وسجّل الدخول.
2. قسم **رابط دفع (واتساب)**:
   - **نوع الخدمة:** ما يظهر للعميل (مثال: «تصميم متجر إلكتروني»).
   - **المبلغ:** بالريال.
3. **إنشاء الرابط** → **نسخ الرابط** أو **واتساب**.
4. بعد الدفع يُغلق الرابط تلقائياً (حالة «مدفوع»). يمكن **إلغاء الرابط** قبل الدفع.

## للعميل

1. يفتح الرابط: `/pay-request.html?link=...`
2. يرى الخدمة والمبلغ → **متابعة الدفع**
3. يدخل البطاقة على `/pay-checkout.html?link=...`

## نشر Firestore

بعد تعديل `firestore.rules` انشر القواعد من Firebase Console أو:

`firebase deploy --only firestore:rules`

## الأمان

- المبلغ يُقرأ من Firestore (لا يُعتمد على تعديل الرابط في المتصفح).
- الرابط UUID يصعب تخمينه.
